---
title: Installation
description: Install Minnow, choose direct SQL or Kysely, and open a database.
---

Install the engine for direct SQL:

```bash
npm install @minnowdb/core
```

Minnow is plain JavaScript. It has no post-install step, native binary, or WebAssembly module to
fetch at runtime.

Add the Kysely adapter if you want a type-safe query builder:

```bash
npm install @minnowdb/kysely kysely
```

| Interface          | What it provides                                               |
| ------------------ | -------------------------------------------------------------- |
| `@minnowdb/core`   | Direct SQL through `query()` and `execute()`.                  |
| `@minnowdb/kysely` | A Kysely dialect whose `DB` type derives from Minnow's schema. |

Every `@minnowdb` package in one application must use the same major version. npm selects a
compatible engine version from each package's dependency range. See
[Versioning](/docs/reference/versioning).

## Open a database

A database combines the SQL engine with a storage adapter. Start with IndexedDB for durable data
in any supported browser:

```ts
import { MinnowDatabase } from "@minnowdb/core";
import { IndexedDbBlockStore } from "@minnowdb/core/storage";

const store = await IndexedDbBlockStore.open({ name: "shop" });
const db = new MinnowDatabase(store);
```

Use OPFS in a worker when you want its faster file-based storage path:

```ts
import { OpfsBlockStore } from "@minnowdb/core/storage";

const db = new MinnowDatabase(await OpfsBlockStore.open({ name: "shop" }));
```

Use memory for tests and disposable data:

```ts
import { MemoryBlockStore } from "@minnowdb/core/storage";

const db = new MinnowDatabase(new MemoryBlockStore());
```

See [Storage](/docs/storage) for the availability, durability, and performance trade-offs.

## Run it in a worker

Most interactive applications should put the engine in a worker so query execution does not
compete with rendering. `MinnowDatabaseClient` exposes the same query, write, migration, live
query, snapshot, and maintenance calls on the main thread.

The [worker guide](/docs/engine/workers) includes the ready-made worker entry and bundler setup.

## Browser requirements

Minnow needs `CompressionStream` plus a storage adapter. Current Chrome, Firefox, Safari, and Edge
support IndexedDB in a window or worker. OPFS requires a worker and is unavailable in Safari
private browsing.

Minnow targets browsers. It does not ship a Node.js engine build. Use `MemoryBlockStore` or
`fake-indexeddb` for Node-based tests.

## Package entry points

| Import                           | What it contains                                                                   |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| `@minnowdb/core`                 | `MinnowDatabase`, SQL, schema management, catalog access, and engine types.        |
| `@minnowdb/core/storage`         | IndexedDB, OPFS, and memory stores plus the shared `BlockStore` interface.         |
| `@minnowdb/core/client`          | `MinnowDatabaseClient`, the main-thread API for a worker-hosted engine.            |
| `@minnowdb/core/worker`          | The ready-made worker entry.                                                       |
| `@minnowdb/core/plan`            | Low-level plan-building tools for custom query layers.                             |
| `@minnowdb/core/storage/toolkit` | Reusable parts for [custom storage adapters](/docs/storage/custom).                |
| `@minnowdb/core/testing`         | Fault injection, deterministic simulation, SQLLogicTest, and the storage test kit. |
| `@minnowdb/core/block-format`    | The stored block encoding for tools that inspect blocks directly.                  |
| `@minnowdb/core/transactions`    | Low-level snapshots, transactions, and recovery tools.                             |
| `@minnowdb/core/worker-protocol` | Worker request, response, and event types.                                         |
| `@minnowdb/kysely`               | The optional Kysely dialect and schema-to-Kysely type inference.                   |
| `@minnowdb/devtools`             | The optional SQL console and data browser.                                         |
