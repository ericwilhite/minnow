Benchmarks & test suites

Three independent suites. Reference queries verify results against hand-written JavaScript oracles; the storage matrix measures MinnowDatabase's own configuration space; the conformance run executes the documented SQL surface live.

Reference query suite

15 relational queries over a persisted dataset. Each engine prepares once and executes seven measured iterations per query; every result is compared tuple-for-tuple against an independent JavaScript oracle computed from the deterministic generator. A query an engine cannot compile is reported as outside that engine's surface, with the engine's own error.

Storage configuration benchmark

MinnowDatabase only: writes and reads back the full dataset through the block store, verifies every value, probes transaction conflicts and recovery, benchmarks the write API, and runs the reference queries with JavaScript baselines. Uses throwaway databases; nothing is retained. “Full matrix” runs raw/rle/gzip across five block sizes.

SQL conformance run

Executes every example from the shipped feature matrix live. Supported examples must run on MinnowDatabase; unsupported examples must still fail with the recorded error (drift detection). SQLite Wasm and PGlite run the same statements against an identical in-memory fixture, so the table also shows honestly where other engines support something this engine does not.
