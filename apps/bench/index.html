MinnowDatabase

A persistent columnar SQL database that runs entirely in the browser. Data lives in IndexedDB as immutable compressed column blocks; queries run through a vectorized executor with bounded memory. No server, no sync layer, no build-time codegen.

This site is the library's documentation and its measurement bench. Every number shown anywhere here is produced live in your browser, and the same deterministic datasets can be loaded into SQLite Wasm and PGlite for comparison.

What it does

SQL

Prepared queries over immutable snapshots: joins, grouping, CTEs (including recursive), window functions, set operations. The exact surface is documented and executable on the SQL support page.

Columnar storage

Typed column blocks (boolean, number, string, datetime) encoded raw, run-length, or gzip, stored in IndexedDB with checksums and exact size accounting.

MVCC writes

Journaled transactions publish atomically; readers keep stable snapshots; competing writers conflict, rebase, and retry through the public API.

Typed schema & migrations

A schema DSL with inferred row types, planned idempotent migrations, and optional Standard Schema validators at the write boundary.

Query builder

A typed builder that compiles to the same plans as the SQL text front end — one executor, two front ends.

Live queries

Registered queries re-execute selectively when the tables they reference change, driven by persisted change sets and digest notifications across tabs.

Bounded memory

The vectorized executor works in batches under an explicit memory budget and can spill; whole tables are never required to be resident.

Maintenance

Compaction, garbage collection, and backup run as stepped, cancellable jobs with the same snapshot guarantees as everything else.
